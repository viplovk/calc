## 🌟 Overview

**CALCX** is a modern, responsive web application designed to go far beyond standard calculators. Built completely from scratch using clean vanilla web technologies, it offers an immersive dashboard packed with advanced mathematical tools, matrix operations, equation solvers, calculus utilities, and unit conversions—all inside a sleek, distraction-free interface.

---

## ✨ Key Features

* **Advanced Scientific Calculator:** Full trigonometric suite (sin, cos, tan and their inverses), logarithms ($\log, \ln$), square roots, powers, factorials, percentages, and memory functions ($\text{MC}, \text{MR}, \text{M+}, \text{M-}$).
* **Dynamic Angle Modes:** Seamlessly toggle between Degrees ($\text{DEG}$), Radians ($\text{RAD}$), and Gradians ($\text{GRAD}$).
* **Matrix Calculator:** Perform addition, subtraction, multiplication, transposition, find determinants, and calculate inverses for $2 \times 2$ and $3 \times 3$ matrices.
* **Equation Solver:** Solve linear ($ax + b = 0$) and quadratic ($ax^2 + bx + c = 0$) equations with support for complex roots and discriminants.
* **Statistics & Data Set Analyzer:** Input comma-separated data sets to instantly compute count, sum, mean, median, mode, range, variance, and standard deviation.
* **Calculus Tools:** Compute numerical derivatives via central difference and definite integration using Simpson's rule.
* **Unit Converters:** Quickly switch values across length, area, mass, temperature, speed, time, angles, and pressure.
* **Base-N Conversion:** Convert exact integers seamlessly between Decimal, Binary, Octal, and Hexadecimal formats.
* **Combinatorics:** Calculate factorials, permutations ($nPr$), and combinations ($nCr$).
* **Calculation History:** Keeps track of your past entries so you can review or instantly reuse them with a single click.
