CALCX GUIDE

How to use it

Everything you need to get started.

⌕
01

Start with Basic mode

For normal calculations, simply enter the numbers and operators and press =.

25 × 4 + 10 = 110
02

Use Scientific mode

Switch to Scientific when you need trigonometry, logarithms, powers or roots.

sin(30) = 0.5
03

Choose the correct angle

DEG is normally used for angles written with °. Use RAD for radians.

sin(30°) → DEG
04

Working with matrices

Open Matrix mode, select 2×2 or 3×3, enter your values and select an operation.

A × B → Matrix multiplication
05

Memory

  • MC — Clear memory
  • MR — Recall memory
  • M+ — Add result
  • M− — Subtract result
06

Need more help?

Search this guide for terms such as matrix, sin, memory, factorial or radians.
