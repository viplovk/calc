CALCX GUIDE

How to use it

Beginner-friendly calculator guide.

01

Basic calculations

Enter numbers and operators and press =. Brackets are supported.

25 × 4 + 10 = 110
02

Scientific mode

Scientific mode adds trigonometry, logarithms, roots and powers.

sin(30) = 0.5 in DEG
03

DEG / RAD / GRAD

Use DEG for degree angles, RAD for radians and GRAD for gradians.

04

Matrix calculator

Select 2×2 or 3×3, enter values into A and B, then choose an operation.

A × B • det(A) • A⁻¹ • Aᵀ
05

Equation solver

Linear equations use ax+b=0. Quadratic equations use ax²+bx+c=0.

2x² + 5x − 3 = 0
06

Statistics

Enter values separated by commas. The calculator gives descriptive statistics.

4, 7, 8, 10, 12
07

Calculus

Enter functions using x. The derivative uses a central numerical difference and integration uses Simpson's rule.

x² + 3x → f′(2) = 7
08

Memory

  • MC — clear memory
  • MR — recall memory
  • M+ — add answer
  • M− — subtract answer
09

Keyboard

Enter calculates, Escape clears, and Backspace deletes.
