Getting started

Enter numbers using the keypad and press = to calculate.

Example 25 × 4 + 10 = 110
📐

Trigonometry

Use sin, cos and tan for triangle and angle calculations.

Example sin(30) = 0.5 Make sure DEG is selected when using degrees.
🔢

Powers and roots

Use x² for squares, xʸ for powers and √ for square roots.

Examples 5² = 25 √81 = 9
🧮

Order of operations

The calculator follows normal mathematical order:

  1. Brackets
  2. Powers and roots
  3. Multiplication and division
  4. Addition and subtraction
Example 2 + 3 × 4 = 14
🧠

Memory buttons

  • MC — Clear memory
  • MR — Recall memory
  • M+ — Add to memory
  • M− — Subtract from memory
